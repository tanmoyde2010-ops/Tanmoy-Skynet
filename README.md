        ▼

        │
        ▼

### 📄 Sample YAML Pipeline (Azure DevOps Best Practice)

```yaml
# azure-pipelines-terraform.yml — Validate Pipeline

trigger:
  branches:
    include:
      - feature/*
      - fix/*

pool:
  vmImage: 'ubuntu-latest'

variables:
  - group: terraform-secrets           # Key Vault linked variable group
  - name: TF_VAR_environment
    value: 'prod'
  - name: backendRG
    value: 'rg-terraform-state'
  - name: backendStorageAccount
    value: 'sttfstateproduction'
  - name: backendContainer
    value: 'tfstate'

stages:
  - stage: TerraformInit
    displayName: '🔧 Terraform Init'
    jobs:
      - job: Init
        steps:
          - task: TerraformInstaller@1
            inputs:
              terraformVersion: 'latest'

          - task: TerraformTaskV4@4
            displayName: 'Terraform Init'
            inputs:
              provider: 'azurerm'
              command: 'init'
              backendServiceArm: 'AzureServiceConnection'
              backendAzureRmResourceGroupName: $(backendRG)
              backendAzureRmStorageAccountName: $(backendStorageAccount)
              backendAzureRmContainerName: $(backendContainer)
              backendAzureRmKey: 'prod.terraform.tfstate'

  - stage: TerraformValidate
    displayName: '✅ Terraform Validate'
    dependsOn: TerraformInit
    jobs:
      - job: Validate
        steps:
          - task: TerraformTaskV4@4
            displayName: 'Terraform Validate'
            inputs:
              provider: 'azurerm'
              command: 'validate'

  - stage: TerraformPlan
    displayName: '📋 Terraform Plan'
    dependsOn: TerraformValidate
    jobs:
      - job: Plan
        steps:
          - task: TerraformTaskV4@4
            displayName: 'Terraform Plan'
            inputs:
              provider: 'azurerm'
              command: 'plan'
              commandOptions: '-out=$(Build.ArtifactStagingDirectory)/$(Build.BuildId).tfplan'
              environmentServiceNameAzureRM: 'AzureServiceConnection'

          - task: PublishBuildArtifacts@1
            displayName: '📦 Publish Plan Artifact'
            inputs:
              PathtoPublish: '$(Build.ArtifactStagingDirectory)'
              ArtifactName: 'terraform-plan'

---
# azure-pipelines-apply.yml — Apply Pipeline (Post PR Merge)

trigger:
  branches:
    include:
      - main

stages:
  - stage: TerraformApply
    displayName: '🚀 Terraform Apply'
    jobs:
      - deployment: Apply
        environment: 'production'        # ← Manual approval gate configured here
        strategy:
          runOnce:
            deploy:
              steps:
                - task: DownloadBuildArtifacts@1
                  inputs:
                    buildType: 'specific'
                    artifactName: 'terraform-plan'

                - task: TerraformTaskV4@4
                  displayName: 'Terraform Apply'
                  inputs:
                    provider: 'azurerm'
                    command: 'apply'
                    commandOptions: '$(Pipeline.Workspace)/terraform-plan/$(Build.BuildId).tfplan'
                    environmentServiceNameAzureRM: 'AzureServiceConnection'

                - script: |
                    echo "✅ Infrastructure deployed successfully!"
                    echo "🔍 Running post-deploy health checks..."
                  displayName: 'Post-Deploy Validation'
```

## 🔀 Trunk-Based Development — My Branching Strategy

<div align="center">

```
                         ┌─────────────────────────────────┐
                         │   TRUNK-BASED DEVELOPMENT        │
                         │   (Short-lived Feature Branches) │
                         └─────────────────────────────────┘

MAIN (trunk) ────●────────────────────●────────────────────●────► PRODUCTION
                 │                    │ ↑                   │
                 │                    │ │  PR + Approval     │
              feature/xyz          feature/abc           fix/bug-123
              (< 2 days)           (< 2 days)            (< 1 day)
                 │
                 ▼
            Pipeline Triggers:
            ✅ terraform init → validate → plan
            📋 PR Created → Review → Manual Approve
            🚀 Merge to main → Apply Pipeline
```

**Why Trunk-Based Development?**

</div>

- 🚀 **Continuous Integration** — Every commit triggers the validation pipeline
- 🔒 **Branch Protection** — Main branch protected with required PR reviews
- 📋 **Short-Lived Branches** — Features merged within 24-48 hours, reducing merge conflicts
- 🤖 **AI-Assisted Reviews** — GitHub Copilot reviews PRs for security and best practices
- ✅ **Feature Flags** — Large changes deployed behind toggles for safe rollout
- 🔄 **Automated Rollback** — Failed deploys trigger automatic revert pipelines
